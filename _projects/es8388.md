# ES8388 Breakout Board

This is a breakout board for the ES8388, a high performance, low poer and low cost CODEC.  It exposes all pins on the chip and also includes a headphone jack wired to ROUT2/LOUT2 - making is easy for quick testing.

## Features

### ADC
- 24-bit, 8KHz to 96KHz sampling frequency
- 95 dB dynamic range, 95dB signal to noise ratio, -85 dB THD+N
- Stereo or mono microphone interface with microphone amplifier
- Auto level controls and noise gate
- 2-to-1 analog input selection
- Various analog input mixing and gains

### DAC

- 24-bit, 8KHz to 96KHz sampling frequency
- 95 dB dynamic range, 95dB signal to noise ratio, -85 dB THD+N
- 40 mW headphone amplifier, pop noise free
- Headphone capless mode
- Stereo enhancement
- Bass and Trebble
- Various analog output mixing and gains
